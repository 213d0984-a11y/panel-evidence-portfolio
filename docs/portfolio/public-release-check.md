## 作品の提示範囲

複数の技術PDFを検索し、型式・仕様に対応する資料名・PDF物理ページ・原文を確認する、ローカル・単一利用者向けのポートフォリオです。標準の原文モードは外部LLM APIを必要としません。質問に十分な直接根拠が見つからない場合は回答を控えます。

原文の提示と、対象型式の仕様値を簡潔に抜き出すことは区別しています。固定28問の回答可否27/28・厳格条件26/28は、仕様値と適用条件の完全正答率ではありません。回答可能23問のうち全要求の型付き値提示は3/23です。省略型式・別名や複雑な条件表には誤拒否・条件の読み落としが残り、技術者による原本確認が必要です。
