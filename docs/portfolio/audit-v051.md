# v0.5.1：独立監査からのローカル修正

2026-10-24。基準はv0.5.0、commit `d6de6a46751a18d5538268234cc66bea27efaf26`。監査資料・初回結果・固定28問・正解参照は変更しない。レビュー用チャット本文は取得できておらず、その内容を推測して変更したものではない。

## 原因と修正

- 「定格出力電力」が既存の仕様語に含まれず、根拠があるのに拒否された。電力の一般的な仕様語を追加した。
- 「適用条件」を未知の別仕様として拒否した。条件要求を認識し、対象型式・仕様の合格したfactに条件がある場合だけ認める。他製品・別項目の条件を借用しない。
- PDF抽出器がMODELのセルへ表全体を混ぜ、型式列の対応が失われた。実在するMODEL文字と水平に揃う型式セルだけで見出しを復元する。値は補完しない。INPUT/OUTPUTの適用範囲は、実在する文字と表全幅の罫線による区切りがある場合だけ使用する。
- RATED CURRENT / RATED POWERはOUTPUT範囲を要件にする。出力電圧調整範囲は公称出力電圧とは別項目にし、公称値だけで回答しない。
- ラベル・値の明示条件と、参照番号の一致する同ページの脚注を保持する。重複定義や未確認の脚注を伴う値は回答に使わない。小数値を脚注番号と誤認しない。`Note`・番号付き・アスタリスクの脚注と同一ブロックの継続行を扱う。

メーカー名・PDF名・問題ID・正解ページ・答えの数値によるアプリ側の分岐はない。Embedding、チャンク、Top-K、検索閾値、LLM Providerは変更していない。

## 検索・出典と、直接値提示の区別

固定28問は可否27/28、厳格26/28、文書取得100%、ページ取得97.8%、不能5/5拒否、誤拒否1/23を維持。直前版から悪化0問。A-02の引用ページ差、C-03の別名対応不足は残る。

固定28問の回答可能23問で、全要求の型式・項目を構造化した値で提示できたのは3問（B-04/C-04/C-06、13.0%）。他の原文・混在提示を、直接数値回答の成功に数えない。`complete_bound_value_presentation_rate`は提示経路の被覆であり、数値・単位・適用条件の完全正答率ではない。値の正確性は原本照合で別に確認する。

C-06は原本のVA/VB共通列に従い、75℃と注4の出力ディレーティング曲線参照を回答へ保持した。凍結された70℃の正解参照を修正・採用してスコアを作っていない。

## 再現

プロジェクトをインストールしたPythonで実行する。新規キー・有料APIは不要。

~~~powershell
python -m pytest -q --junitxml=data/tests.xml
python scripts/evaluate_benchmark.py --dataset benchmarks/hdr60.json --documents data/independent/hdr60 --storage data/eval-hdr60 --output data/eval-hdr60/report.json
python scripts/evaluate_benchmark.py --dataset benchmarks/fixed28.json --documents data/documents/real_world --storage data/eval-fixed28 --output data/eval-fixed28/report.json
~~~

原本は公式配布元から別途用意する。ファイル名・原本ハッシュが一致しなければ停止する。保存先には空の専用フォルダを使う。同一の登録原本を再検証するときは`--reuse-index`を指定できるが、台帳のファイル名とハッシュが固定データセットに完全一致する場合だけ実行する。索引や原本を削除・上書きしない。
