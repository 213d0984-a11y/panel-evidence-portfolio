## 構成と編集

| 完成版 | 内容 | 使用した原本区間 |
|---|---|---|
| 0–5秒 | 技術PDFを横断検索し、仕様を根拠から確認する価値 | 説明カード |
| 5–13秒 | 登録済みの自作PDF3冊・7ページ | 7–15秒 |
| 13–19秒 | PS-24Nの電源電圧を質問 | 38–44秒 |
| 19–26秒 | DC12～24V ±10%の原文を拡大 | 15–22秒 |
| 26–33秒 | 資料名・PDF物理ページ1・該当原文 | 24–31秒 |
| 33–45秒 | Bluetooth仕様の根拠不足による回答拒否 | 46–58秒 |
| 45–54秒 | 固定28問の回答可否27/28と指標の注意 | 説明カード |
| 54–60秒 | 検索・根拠確認の効率化と、人による最終確認 | 説明カード |

原本は約85.44秒・1440×1000・VP8・無音。実画面部分は等速で再利用し、長い待機部分をカット。ゆるやかな拡大・枠線と、画面外の大きな説明文字を追加しました。画面を縦横別倍率で伸ばさず、対象の情報を見せるクロップと余白配置を使用。短い場面切り替えは約0.24秒です。

アップロード・文字入力・未実装機能の操作映像を合成していません。「登録済み資料」と「アップロード操作は映っていない」ことを明記。初稿の境界確認で、次の質問への入力切り替えが質問紹介の末尾に入り込んでいたため、採用区間を38–44秒へ変更して再検査しました。

## 機能・数値の表現

映像はAPI不要の標準抜粋モード。自然文生成の完成機能や、設計判断・誤回答ゼロを謳いません。複雑な表・条件・矛盾は技術者が原本で確認する旨を表示しました。

表示した数値は**v0.5.2・実メーカーPDF12冊・固定28問で回答可否27/28**だけです。`eval/fixed28-v052-results.json`と公開集計`handoff-v052-metrics.json`を照合し、v0.5.1の独立監査記録でも27/28だったことと、バックエンドが同一であることを確認しました。これは回答する／控えるという判定の一致数であり、**回答本文の完全正答率ではない**と大きく表示しています。旧動画の評価画面（68–85秒）と「新規資料10問・90%」は使用していません。既存評価は読み取りだけです。

## 実施した検証

- 原本も最初から最後まで再生して確認。完成版は修正版で再度、**等速・シークなしで60秒を完走、再生エラー0**。Windowsの既存Chromeを使用。実測60.153秒、waiting通知1回も記録しています。通知発生位置は記録しておらず、停止なしという数値へ書き換えていません。
- FFmpegで完成ファイルの**全1,500フレームをデコード、エラー0**。1920×1080・25fps・H.264・yuv420p・音声なし、先頭に索引を置くfaststart形式を確認。
- 各場面、切り替え前後、最終フレームを画像で確認。480px幅の縮小表示でも、目的・型式・仕様値・ページ番号・拒否・評価の注意が主要テロップから読み取れることを確認。細かいアプリ原文はPC表示での照合を想定します。
- 原本WEBM／原本SRTのSHA-256一致、既存の追跡ファイルに変更なし、凍結入力・バックエンド35件のハッシュ一致を確認。アプリ・評価・過去の配布物は変更していません。
- BGM・ナレーション・外部素材は追加せず、Windows標準フォントを文字画像として描画。フォント本体は同梱・埋め込みしません。[Microsoft公式FAQの動画字幕に関する説明](https://learn.microsoft.com/en-us/typography/fonts/font-faq)を確認しました。

クラウドワークスへのアップロード後再生、他ブラウザ・スマートフォン実機は未確認です。アプリ再収録、有料API、外部LLM、GitHub push、他の作業プロセスの停止は行っていません。
